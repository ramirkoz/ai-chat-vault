## Description (English)

AI Chat Vault keeps your AI conversations — from ChatGPT, Claude, Gemini and Grok — in one place, on your computer.

EXPORT ANY CHAT
• Markdown, HTML, PDF or JSON — the whole chat or only the messages you pick.
• ZIP with files: attachments, images and generated files are downloaded next to the transcript, each linked from its message. Large exports are split into parts automatically.
• Reads the chat through the site's own data, not by scraping the screen, so long chats come out complete.

ONE LIBRARY FOR EVERY ASSISTANT
• Save chats to a local library, organise them with folders, tags and notes.
• Full-text search across all saved chats from all assistants.
• Insert what you found as context into your current chat.
• Export selected chats as one ZIP, back up and restore the library.

CONTINUE IN ANOTHER ASSISTANT
• Move a conversation from ChatGPT to Claude, from Gemini to Grok — any direction. The transcript is placed in a new chat for you to review and send.

PROJECT MEMORY FOR CHATGPT
• Optional. Chats of a ChatGPT Project are kept locally, and the first message of a new project chat gets the most relevant excerpts from earlier chats in front of it.

PROMPT LIBRARY
• Save your prompts and insert them into the current chat or a new chat in any assistant.

FROM ANY WEB PAGE TO A CHAT
• Send selected text, the page text, a screenshot of the visible area or YouTube subtitles to a new chat — from the side panel or the right-click menu.

PRIVATE BY DESIGN
• No account, no server, no analytics. Your chats, prompts and library never leave your browser.
• Access to each AI site is asked separately, only when you first use it there.
• Nothing is ever sent to an assistant automatically.

## Single purpose

Local tools for the user's own AI chat conversations: reading, exporting, saving, searching and continuing them across ChatGPT, Claude, Gemini and Grok, and putting user-selected web content into a new chat.

## Permission justifications

- **activeTab:** read the selection, page text or visible screenshot of the tab where the user invoked the extension.
- **scripting:** run the conversation reader and composer insertion in the chat page, and the page-text reader in the active tab, after a user action.
- **sidePanel:** the extension's interface is a side panel next to the chat.
- **contextMenus:** right-click actions to send selected text, page text, a screenshot or YouTube subtitles to a chat.
- **downloads:** save exports, ZIP archives and backups chosen by the user.
- **storage:** prompts, settings and short-lived data (a prepared page waiting for the user to choose an assistant).
- **Optional hosts (chatgpt.com, chat.openai.com, claude.ai, gemini.google.com, *.googleusercontent.com, grok.com):** read the user's conversations and their files on those sites and insert text into their chat input. Requested per site at first use. googleusercontent.com hosts Gemini's images, which are included in ZIP exports.
