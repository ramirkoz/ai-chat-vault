# Chrome Web Store listing — GPT Project & Memory Tools 2.33.0

## Product name

GPT Project & Memory Tools

## Description

GPT Project & Memory Tools adds a local workspace to ChatGPT for project continuity, conversation export, reusable prompts, saved chats, and attachment handling.

Keep useful project context available between conversations inside ChatGPT Projects. Project memory is stored locally in your browser and does not require a developer-operated server.

Export selected messages or complete conversations together with available attachments. The extension preserves conversation structure and reports files that are no longer available from the source.

Save frequently used prompts locally and reuse them across conversations.

Include accessible conversation attachments in exports, remove duplicate copies, preserve useful filenames, and clearly report unavailable files.

Project memory, saved prompts, and extension settings are stored locally in the browser. The extension does not operate its own remote data collection service.

GPT Project & Memory Tools is an independent browser extension and is not affiliated with or endorsed by OpenAI.

## Single purpose statement

GPT Project & Memory Tools provides user-triggered local tools for maintaining ChatGPT project context, exporting conversations, reusing prompts, and handling available conversation attachments.

## Permissions

### activeTab

Used only for the active page where the user explicitly invokes the extension.

### scripting

Used to read the user-requested conversation or page content and perform the selected local workflow.

### downloads

Used to save user-requested exports and backups locally.

### storage

Used for local project memory, saved prompts, workspace data, and extension settings.

### Optional ChatGPT host access

Requested only when a user-triggered feature needs access to ChatGPT pages. No broad mandatory host permission is requested.

## Remote code

No. All executable code is packaged inside the extension.

## Data usage

The extension processes user-requested content locally for project memory, export, organization, backup, and attachment handling. It does not sell user data, use data for advertising, or transmit user content to a developer-operated service.
